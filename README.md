# Antigravity 用量看板

在 Antigravity 桌面端查看当前会话的 Token、缓存命中率、生成速率和上下文窗口。悬停顶部「用量看板」可查看当前会话和近 7 天合计的美元、人民币 API 参考费用。点击后可在原窗口内按日期查用量、费用、汇率和模型额度。看板按用量分析布局组织：顶部是 2×2 的指标卡（参考费用、请求数、Token 总量、缓存命中率），与下方的用量柱状图共用一张卡片，中间的折叠钮可以把趋势图收起；柱状图可按金额/Token/次数切换（悬停高亮单柱并显示该时段明细），纵轴按数值大小使用万、亿单位、按费用排序且名字—条形—金额三列对齐的模型分布，以及每日、模型、调用、会话、额度五个明细视图（Tab 上标出各自条数）。范围可切到当天、24 小时、7 / 14 / 30 天或全部；24 小时与当天按小时聚合，柱状图横轴直接显示小时，明细表首列随之变成「时刻」。明细视图可切每日、模型、调用、会话、额度，各自标出条数；切换时间范围时视图回到「每日」，不会残留上一个视图的列。

## 安装

适用于 Windows x64，已在 Antigravity 桌面端 2.32.1 验证。先从 GitHub 的 **Releases** 下载 `antigravity-usage-*-win-x64.zip`，完整解压后双击 **`Install.cmd`**。发布包包含 Python 运行环境，不需要额外安装依赖或使用管理员权限。

以后使用原来的入口打开 Antigravity，插件会由 Antigravity 自动启动。如果安装时 Antigravity 已打开且没有立即出现用量栏，请退出后重开一次。安装成功后可以删除解压出的副本。卸载时在保留的发布包或重新下载的发布包中运行 **`Uninstall.cmd`**。

**已安装过的用户**下载新版 ZIP，解压后双击新版里的 **`Install.cmd`** 即可原地升级。安装程序会替换插件文件，原有会话、用量记录和设置会继续使用。

插件安装在 `%USERPROFILE%\.gemini\config\plugins\agy-usage`，通过 [官方 Sidecar 机制](https://antigravity.google/docs/sidecars/) 随 Antigravity 启动。桌面界面通过客户端本机调试接口接入，客户端大版本更新后可能需要适配。日志位于 `%LOCALAPPDATA%\AntigravityUsage\composer.log`。

## 用量口径

- 顶部额度旁的「任务进度」优先读取本轮 Antigravity 原生任务清单，折叠清单后也会更新；没有原生记录时读取本轮计划文件。只有读到任务清单才显示进度环和已完成百分比。
- 顶部「运行中」显示正在执行或仍有后台活动的主会话数。悬停或点击可查看列表并跳转，子任务计入所属主会话。
- 上方用量趋势图支持在「柱状图」和「热力图」之间切换，两种图共用费用、Token 用量、请求数指标及顶部日期筛选。用量热力图可按模型多选，颜色深浅表示数值高低。费用中的虚线方格代表有调用但未能计价。
- 下方模型调用健康热力图单独提供「最近 24 小时」「本月」「全部」及模型多选。绿色代表有记录且无异常，红色代表有异常。两处热力图都可悬停、点击或键盘聚焦方格查看时段明细，较长历史可翻页。

- 输入框底部保持单行，随所选模型、思考强度和窗格宽度即时调整。会话、Token 和上下文指标分别按实际余量显示完整读数或简写，未能排入的读数可以点用量图标查看。若省略了部分模型名称，悬停可看全名。
- 标签详情固定时，悬停「用量看板」会保留该详情。再次点标签、按 Esc 或点外部可解除固定。点击「用量看板」可直接打开完整看板。
- 上下文圆环用同一条匹配调用的用量和窗口预算计算。压缩和新一轮调用之间保留上一条有效读数，详情会注明。客户端写入新的上下文记录后更新读数。首次调用还没有记录时显示「待读数」。右上角的 5 小时和周额度按客户端返回的模型组与周期展示。
- 历史统计覆盖本机可读的 Antigravity 会话。累计 Token 含输入、缓存读写和输出；缓存命中率按缓存读取除以输入 Token 计算。
- 会话顶部的「X 轮 Y 步」同时给出本会话的上下文压缩次数，看板的会话卡片与每日汇总里是同一个数字；压缩次数按会话库里的 checkpoint 步骤统计，不需要解析步骤载荷。
- Antigravity 运行时，插件按北京时间每日后台核验公开价格和模型分工，状态显示在看板底部。历史日期使用当时保存的版本。有明确生效日期的价格按公布日期切换，未注明日期的变化从首次核验日起启用。暂时无法访问来源时继续使用上次成功数据，首次离线则使用内置快照。费用逐条根据本机调用记录折算，能确认的规划和执行记录分别计价，无法确认模型或价格的记录只计 Token。来源为 [Antigravity 模型文档](https://antigravity.google/docs/models)、[Google Cloud 模型定价](https://cloud.google.com/model-garden/pricing) 和 [合作模型价格](https://cloud.google.com/model-garden/partner-models/pricing)。
- 悬停卡片的近 7 天按北京时间统计，含今天及之前 6 天的本机用量。启动时从 [Frankfurter](https://frankfurter.dev/) 读取最新 USD/CNY 参考汇率，用于悬停卡片的人民币金额。历史看板按用量发生日期折算。汇率请求只包含币种和必要的日期范围，接口不可用时回落到最近一次成功获取的汇率或内置离线值，并在看板上标注当前口径。

## 从源码构建

使用 Python 3.10 或更新版本运行 `python build_release.py`，生成的 ZIP 和 SHA-256 校验文件位于 `dist/`。脚本从 Python.org 和 PyPI 取固定版本运行环境并校验 SHA-256。

上传源码到 GitHub 后，可在 Actions 手动运行 Windows release 工作流取得构建产物，或推送和 `plugin.json` 一致的版本标签（例如 `v1.1.4`）发布到 Releases。

## 发布新版本

改完源码后把 `plugin.json` 的 `version` 加一，然后在仓库根目录双击 **`Publish.cmd`**（或在终端运行 `python release.py`）。一条命令依次完成：在 `dist/` 构建便携包与源码包 → 更新 `.gitignore` 放行当前版本、把旧版本包移出索引 → 提交 → 打 `V<版本>` 标签 → 推送 → 创建或更新同名 Release 并上传两个 zip。首次运行会要求一次 GitHub 授权（设备码），token 缓存在 `%LOCALAPPDATA%\agy-release\config.json`，之后不再询问。常用开关：`--no-build` 复用已有包，`--dry-run` 只打印计划，`--force-upload` 覆盖同名附件，`--no-push` 只提交不推送，`--actions` 只推送标签交给云端出包，`--login` 单独完成授权。

云端也可以出包：`.github/workflows/release.yml` 在推送 `V*` 标签时用 Windows runner 构建并发布，`--actions` 模式即走这条路径。本地脚本适合离线或需要立刻看到产物时用，两种方式互为备份。
